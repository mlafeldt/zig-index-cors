Zig build index mirror

A CORS-enabled mirror of ziglang.org/download/index.json.

The upstream index ships no Access-Control-Allow-Origin header, so browsers cannot fetch it directly. GitHub Pages serves everything with Access-Control-Allow-Origin: *, which makes this copy usable from any web page.

Endpoints

index.json
Byte-for-byte copy of the upstream index.
meta.json
When the copy was taken, plus upstream Last-Modified / ETag.

Usage

const res = await fetch(
  "https://mlafeldt.github.io/zig-build-index/index.json",
);
const index = await res.json();
console.log(index.master.version);

Freshness

A GitHub Actions job re-fetches the upstream index every hour and commits it only when it actually changed. Upstream itself publishes a new master build about once a day.
